## 1. Enunciado e Instruções do Professor

Produzir um "vídeo pitch", com duração máxima de 5 minutos. Este "vídeo pitch" deve conter:

1. Apresentação da proposta do projeto Challenge SPI Metaindústria / FIAP: Qual é o desafio e qual problema/necessidade o projeto está resolvendo/atendendo.

2. Apresentação das funcionalidades do projeto que o tornam inovador.

3. Apresentação da Arquitetura da Solução:

(A) Descrição das principais tecnologias, hardware e módulos de software que estão sendo utilizados no desenvolvimento do projeto: linguagens de programação, frameworks, IDEs, SGBDs, APIs, bibliotecas de software, componentes em nuvem, ferramentas de analytics, dashboards, integrações com Web services de terceiros, orquestradores, softwares utilizados para apoiar o desenvolvimento do projeto (levantameto de requisitos, estimativa de esforço, teste, validação etc.), componentes físicos, circuitos etc.

(B) Elaboração do diagrama da solução, indicando as integrações entre os vários componentes de hardware e software.

4. Apresentação de partes funcionais do Protótipo:

Mostrar as principais funcionalidades do projeto: DEMONSTRAR O FUNCIONAMENTO DO PROTÓTIPO.

É desejável que o projeto esteja próximo do pleno funcionamento. Apresente mesmo que a solução esteja parcialmente funcionando.

5. Perspectivas:

Explicar o que falta desenvolver até a entrega do projeto.

6. Mostrar, brevemente, os principais códigos desenvolvidos.

ATENÇÃO: o objetivo principal deste vídeo pitch é mostrar o protótipo funcionando. Assim, dedique a maior parte do tempo deste vídeo pitch para o item (4). Os demais itens são para contextualização do projeto.

OBSERVAÇÕES:

a) O "vídeo pitch" deve conter a apresentação da equipe.

b) O "vídeo pitch" deve ser baseado em uma apresentação PowerPoint ou similar.
